# LFI Plattformkonfigurator

Dieser Prototyp bewertet die Plattformfähigkeit anhand eines gewichteten Fragenkatalogs.

## Funktionen
* 11 Fragen mit Punkteskala von 1 bis 5
* Rohscore nach 55-Punkte-System
* gewichteter Gesamtscore
* K.O.-Regeln
* Ableitung des Plattformtyps
* Quellenbezug im Ergebnis

## Installation

```bash
pip install -r requirements.txt
```

## Prototypen starten

```bash
streamlit run app.py
```
